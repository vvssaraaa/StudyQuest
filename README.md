# StudyQuest 📖✨  

this is a gamified student productivity application built with Kotlin and Jetpack Compose for Android.
The goal of this project is to create a mobile application as a practical productivity tool for students, where I want to add functionalties to create study tasks, complete quests and earn XP.
Further i want to add functionalities to maintain study streaks and track progress over time. 

# Planned Features
Create and manage study quests
Set subjects, deadlines, priorities, and XP rewards
Complete quests and earn XP
Level progression
Study streaks
Progress tracking
Local data persistence
Custom themed UI

# Tech Stack
-Kotlin
-Android Studio
-Jetpack Compose
-Material 3
-Android SDK
-Git & GitHub
